# Lucky Number

หน้าเว็บสำหรับคีย์เลข 3 ตัวโต๊ด / 2 ตัวบน / 2 ตัวล่าง สรุปยอดต่อเลข ตัดส่งเป็นรอบ และดาวน์โหลดยอดตัดส่งเป็น Excel

- ไฟล์เดียว: `index.html`
- ข้อมูลเก็บไว้ในเบราว์เซอร์ของเครื่องที่ใช้งาน (localStorage)
- ใช้คีย์บอร์ด: Enter ไล่ช่อง, `/` กลับเลขราคาเดียวกัน, `+` ราคาเดิม, F2 กลับช่องเลข, F8 ตัดส่ง
